Conteúdo do Curso

O que você vai aprender

No desenvolvimento web, o front-end é a
parte visual do site, onde os usuários
interagem. Na Studio Academy,
você
aprenderá a criar páginas dinâmicas e
responsivas com HTML, CSS e JavaScript,
além de explorar
ferramentas como Tailwind
CSS e React para sites rápidos e interativos.

  • Todos
  • Front-end
  • Back-end

  • HTML e CSS


    A estrutura básica de qualquer página
    web, que define a organização e o
    conteúdo e como estilizar e tornar suas
    páginas visualmente atraentes, com foco
    em layouts modernos e responsivos.

  • JavaScript


    Tornando suas páginas interativas,
    adicionando funcionalidades dinâmicas
    que permitem que os usuários interajam
    com o conteúdo.

  • Frameworks e Ferramentas


    Como utilizar Tailwind CSS para criar
    layouts rápidos e customizados, e React
    para construir interfaces dinâmicas e
    escaláveis.
